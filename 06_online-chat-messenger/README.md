# Online Chat Messenger
サーバ操作の基本を身につけるために、Pythonのsocketモジュールを用いて実装したクライアント・サーバ型アプリケーションです。

### 学習したこと
- クライアント・サーバモデルの基本構造
- socket通信の基本（[TCP] bind → listen → accept → recv / send, [UDP] recvfrom / sendto ）
- socketモジュールを用いたプロセス間通信
- `AF_INET`によるIPv4通信
- バイト列（`recv()の返り値`）と文字列の変換（`decode()`）
- `secrets`を用いたトークンの生成
- 外部ライブラリの導入と利用
- カスタムプロトコルの実装

## 機能
このシステムはCLIで動作します。起動したサーバに対して複数のクライアントが接続しメッセージのやり取りをすることができます。クライアントは最初にチャットルームを作成するか参加するかを選ぶことができます。

## 工夫
- ホストが退出もしくはタイムアウトした場合、他ユーザのタイムアウト検出を中止し、即座にルームの削除を実行するようにしました。
- ルームの作成/参加の入力を、正しい入力ができるまで再挑戦できるようにしました。

## 実行方法
1. サーバの起動
```
python3 server.py
```

2. 別ターミナルでクライアントを起動
```
python3 client.py
```

3. ユーザネームを入力
```
> User name: 
```

4. チャットルームの作成(1)もしくは既存のルームへの参加(2)を選択。
```
> enter 1 or 2: 
```

5. 作成もしくは参加するチャットルームの名前を入力。
```
> Room name: 
```

4. `Control` + `C` の割り込みで終了することができます。
